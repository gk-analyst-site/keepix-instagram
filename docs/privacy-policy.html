This Privacy Policy describes how KEEPIX ("we", "our", or "the application") collects, uses, and handles information in connection with our use of the Instagram Graph API.

1. Application Information

  • Application Name: KEEPIX
  • Website: keepix.online
  • Operator: Yasuto Hoshiko
  • Contact: just4keepersjapan@gmail.com

2. Purpose of Data Use

KEEPIX uses the Instagram Graph API solely to manage and analyze content for our own Instagram account (@keepix_gk_official). The application is used internally for content management, performance analysis, and research purposes related to our own account.

3. Information We Collect

KEEPIX accesses and processes the following data through the Instagram Graph API:

  • Public Instagram content retrieved via hashtag search (publicly available posts and metadata).
  • Insights and analytics data for our own Instagram Business account (@keepix_gk_official).

KEEPIX does not collect personal information from end users, and does not request login credentials from any third party. Access to the Instagram Graph API is performed exclusively through credentials owned by the operator.

4. Data Storage and Retention

Retrieved data is stored locally on the operator's own environment solely for analysis purposes. Data is not uploaded to any public server or shared with external services.

5. Sharing of Information

We do not sell, rent, or share any data obtained through the Instagram Graph API with third parties. No user data is transferred to external organizations or advertising networks.

6. Data Security

Access tokens and credentials are stored securely in the operator's local environment and are not exposed publicly. Reasonable technical measures are taken to prevent unauthorized access to stored data.

7. Compliance

KEEPIX complies with the Meta Platform Terms and the Meta Developer Policies.

We may update this Privacy Policy from time to time. Any updates will be posted on this page with a revised "Last updated" date.
